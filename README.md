# Chuck & Co. Pet Care — website

200-page static site (Eugene, OR dog walking & pet sitting), generated from the Claude Design project.

- `build/content.js` — services, neighborhoods, guides, FAQs (edit content here)
- `build/generate.js` — page templates
- `node build/run.mjs` — regenerates everything into `docs/` (served by GitHub Pages)
- `docs/assets/` — `style.css`, `site.js` (lead form → FormSubmit), `img/` stock photos (Unsplash License)
